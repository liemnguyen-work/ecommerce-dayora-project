# Đặc tả giao diện Buổi 2

Tài liệu tổng hợp từ `../css/style.css` hiện có, cần Đạt và Thành đối chiếu giao diện thực tế. DAYORA hướng tới nền sáng, chữ xanh đậm và điểm nhấn đỏ đất; banner trình bày chuyến đi picnic.

| Biến CSS | Giá trị trong mã | Vai trò |
|---|---|---|
| --mau-nen | #fffdf7 | Nền sáng |
| --mau-chu | #23412e | Chữ và nền tối |
| --mau-nhan | #c8483c | Điểm nhấn |
| --mau-nang | #f2c14e | Màu bổ trợ |
| --mau-la | #dde8c9 | Màu bổ trợ |
| --khoang | 16px | Khoảng cách cơ sở |
| --bo-goc | 12px | Bo góc cơ sở |

Font Be Vietnam Pro có font dự phòng sans-serif. Header/footer, thẻ sản phẩm và màu cần nhất quán trên bốn trang; xem CSS và hướng dẫn nhóm để xác định khu sở hữu. Hover, focus và responsive cần được kiểm thực tế; tài liệu này không xác nhận kết quả.
