# Kế hoạch bài tập Buổi 2 — DAYORA

Phạm vi: giao diện tĩnh HTML5/CSS3 cho bốn trang DAYORA; không JavaScript, framework hoặc chức năng giao dịch thật. Kế thừa sáu nhóm hàng và ba tình huống picnic, hẹn hò, đi biển. Kế hoạch và phân công không chứng minh công việc đã hoàn thành.

| Người | Phần việc | Bàn giao cần đối chiếu |
|---|---|---|
| Liêm | Kế hoạch, README, tổng hợp AI và nộp | Kế hoạch, README, báo cáo AI |
| Kiệt | Cấu trúc, ảnh, GitHub | Đường dẫn, nhánh, PR |
| Đạt | Đặc tả UI, màu, hover/focus | ui-design, CSS khu 1 và 8 |
| Thành | Header/footer và trang chủ | index, CSS khu 2–3 |
| Phúc | Danh sách | products, CSS khu 4 |
| Hoàn | Chi tiết | product-detail, CSS khu 5 |
| Châu | Giới thiệu | about, CSS khu 6 |
| Ngọc | Kiểm thử và tích hợp | test-report, ảnh, CSS khu 7 theo hướng dẫn |

## Phụ thuộc

1. Liêm thống nhất nội dung; Kiệt rà cấu trúc và đường dẫn; Đạt chuẩn bị thiết kế.
2. Thành chuẩn bị header/footer; các chủ sở hữu trang làm nội dung song song, phối hợp trước khi thay phần chung.
3. Ngọc kiểm liên kết, ảnh, responsive; chủ sở hữu sửa lỗi; Đạt kiểm hover/focus.
4. Liêm tổng hợp README, bằng chứng, báo cáo AI; mỗi thành viên tự trả lời câu hỏi kiến thức. Kiệt kiểm trạng thái GitHub.

## Nghiệm thu và rủi ro

Bốn trang mở được, danh sách tối thiểu tám sản phẩm, đường dẫn đúng; kiểm 1366/768/390 px, bàn phím và báo cáo kết quả có bằng chứng. Dữ liệu sản phẩm là demo, không khẳng định giá thật. Kiểm xung đột CSS chung, header lệch, ảnh thiếu/quyền dùng chưa rõ, đường dẫn hỏng và thay đổi chưa review. Không đánh dấu đã nộp hoặc kiểm thành công khi chưa có minh chứng. Nguồn phân công: [hướng dẫn Session 2](../../docs/SESSION2-GUIDE.md).
