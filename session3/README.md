# DAYORA — Bài tập Buổi 2

Giao diện tĩnh cửa hàng đồ dùng cho chuyến đi trong ngày, gồm trang chủ, danh sách sản phẩm, chi tiết sản phẩm và giới thiệu. Giá/nội dung sản phẩm chỉ phục vụ bài tập; chức năng tìm kiếm, giỏ hàng và thanh toán chưa được triển khai.

## Mở bài

Mở file `index.html` bằng trình duyệt, rồi dùng menu hoặc liên kết để đến các trang khác. CSS ở `css/style.css`, ảnh ở `images/`; tài liệu và minh chứng ở `docs/`. Font Be Vietnam Pro được tham chiếu qua Google Fonts; khi không tải được, trình duyệt dùng font dự phòng.

## Công nghệ và kiểm tra

HTML5, CSS3, Flexbox, Grid, media query; không dùng JavaScript hoặc framework trong bài. Kiểm tra từng trang ở chiều rộng 1366, 768, 390 px; thử liên kết, ảnh và thao tác Tab. Chỉ ghi đạt khi đã thực sự kiểm và có bằng chứng. Xem [báo cáo kiểm thử](docs/test-report.md), [kế hoạch](docs/plan.md) và [hướng dẫn nhóm](../docs/SESSION2-GUIDE.md).
